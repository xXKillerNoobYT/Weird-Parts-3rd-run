Panel Schedule Builder
Real spaces, real load
Layout switches up top — Classic, List, or Visual (default). Every circuit carries a breaker size (the max) and a connected load (used A); phase balance sums used amps per leg. Four form factors cover what's really in a panel: single/multi-pole, tandem twins, and quads.
Space form factors
1-pole — one space, one leg (120V branch). 2/3-pole ties handles across 2–3 spaces on consecutive legs for 240V / 3Ø.
Tandem (twin) — two 120V circuits in one space, both on the same leg. Builds like 15/15, 20/20, 15/20.
Quad (two spaces) — 4×1P singles, 120/240/120 (two singles + tied inner 2-pole, e.g. 20·30·20), or 2×2P (e.g. 30/50).
info
CTL — a stab-on panel labeled "40/40" only accepts tandems in marked slots; some (QO) fit any space. Set this in Panel setup.
